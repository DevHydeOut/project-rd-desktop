# ProjectRD for Windows

Download the latest installer from the **Releases** page (right-hand side of this page).

1. Download `ProjectRD Setup <version>.exe`.
2. Run it. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.
3. Sign in with your ProjectRD account.

The app updates itself: when a new version is ready it shows a small "Relaunch to update" notice.

Needs help? Contact support@ilayantech.com.

This repository holds downloads only. Nothing else is stored here.
